Daily Akari Tracker非公式

Daily Akari のクリア状況とクリアタイムを記録する非公式ツールです。

  • タイムを自動記録クリアするとタイムを自動で記録し、自己ベストを更新すると🎉お祝い🎊します。
  • クリア状況を確認難易度ごと・作問者ごとに、🌟 パーフェクト／🎯 クリア／未クリアを確認できます。
  • 問題を選択難易度・作問者・クリア状況で絞り込み、問題を選んでそのままプレイできます。

画面イメージ

※数値は架空のものです。

ブックマークレット

次のコードをブックマークとして登録して使います（登録のしかたは下の「導入手順」）。

コピーしました
PC の場合：DATをブックマークバーへドラッグ

導入手順

PC（Chrome・Edge など）

  1. ブックマークバーを表示します（Ctrl + Shift + B）。
  2. 上の「DAT」をブックマークバーへドラッグします。ドラッグできない場合は、ブックマークを新しく作り、URL にコピーしたコードを貼り付けます。
  3. Daily Akari を開き、ブックマークを押します。

スマホ・タブレット（Chrome）

  1. 上の「コピー」を押します。
  2. ブラウザのメニューから、このページをブックマークに追加します。
  3. 下に出る通知の「編集」を押します。
  4. 名前を DAT に、URL をコピーしたコードに置き換えて保存します。
  5. Daily Akari を開き、アドレスバーに DAT と入力して、候補に出てくる☆付きのブックマークを押します。動かないときは、ブックマークの一覧から押します。

アドレスバーに入力したときは、検索の候補ではなく、☆付きのブックマークを押してください。

ブックマークを保存できない、押しても動かないときは、別のブラウザを試してください。

使い方

  • Daily Akari を開いた状態でブックマークレットを実行します。左下に「● 記録中」と出れば準備完了です。
  • 「● 記録中」を押すと各種機能が使えます。
  • ページを再読み込みすると止まるので、再度ブックマークレットを実行してください。
  • ツールを実行していない間のクリアも自動で取り込めます。
  • 記録はブラウザ単位で保存されます。設定からエクスポート・インポートを行うことで別の端末の記録とまとめることができます。

注意事項

  • 非公式のツールです。このツールについて Daily Akari の作者に問い合わせないでください。
  • Daily Akari の非公開の仕組みを利用しているため、Daily Akari の更新によって動かなくなることがあります。
  • 記録は外部へ送信しません。通信が発生するのは、このツール本体の読み込みと、Daily Akari のサイトからの問題取得だけです。
  • Daily Akari 本体の保存データは読み取るだけで書き換えません。
  • 全てのブラウザで検証したわけではないので、一部のブラウザでは動かない可能性があります。
