Daily Akari Tracker非公式

Daily Akari のクリア状況とクリアタイムを記録する、非公式の補助ツールです。Daily Akari の作者とは関係ありません。

  • 成績：難易度別のクリア状況（🌟 パーフェクト／🎯 クリア／未クリア）を帯グラフと一覧で表示します。
  • 問題選択：問題番号を 1 週間ごとに並べ、難易度・ランプ・作問者で絞り込んで、そのままプレイできます。
  • タイム記録：クリアするとタイムを自動で記録し、自己ベストを更新するとお知らせします。

ブックマークレット

次のコードをブックマークとして登録して使います（登録のしかたは下の「導入手順」）。

コピーしました
PC の場合：DA Trackerをブックマークバーへドラッグ

導入手順

Android 版 Chrome

  1. 上の「コードをコピー」を押します。
  2. このページをブックマークに追加します（右上の ︙ → ☆）。
  3. ︙ → 「ブックマーク」を開き、いま追加したブックマークの ︙ → 「編集」を押します。
  4. 名前を DAT など覚えやすいものに、URL をコピーしたコードに置き換えて保存します（URL 欄を長押しして全部選んでから貼り付けます）。
  5. Daily Akari を開き、アドレスバーに名前（例：DAT）を入力して、候補に出てくる☆付きのブックマークを押します。

アドレスバーに入力したときは、検索の候補ではなく、☆付きのブックマークを押してください。ブックマークの一覧から開くと動かないことがあります。

PC（Chrome・Edge など）

  1. ブックマークバーを表示します（Ctrl + Shift + B）。
  2. 上の「DA Tracker」をブックマークバーへドラッグします。ドラッグできない場合は、ブックマークを新しく作り、URL にコピーしたコードを貼り付けます。
  3. Daily Akari を開き、ブックマークを押します。

使い方

  • Daily Akari を開いたら、最初にブックマークレットを実行します。左下に「● 記録中」と出れば準備完了です。あとは普段どおり解くだけで、クリアのたびにタイムが記録されます。
  • 「● 記録中」を押すと、成績と問題選択の画面が開きます（もう一度ブックマークレットを実行しても開閉できます）。
  • サイト内の移動（今日の問題 ↔ アーカイブ）では記録は止まりません。ページを再読み込みしたり、タブを閉じたりすると止まるので、もう一度ブックマークレットを実行してください。
  • ツールを実行していなかったときのクリアも、直前に解いた分はゲームの保存データから取り込めます（起動したときと、画面を開いたときに自動で取り込みます）。
  • 記録はその端末のそのブラウザの中だけに保存されます。別の端末と記録をそろえるには、⚙ の「書き出し」でファイルを作り、もう一方の端末の「読み込み」で読み込みます。読み込みは上書きではなく合算なので、両方の端末で書き出し・読み込みをすると記録が一致します。
    • インポートは上書きではなく合算なので、両方の端末でエクスポート・インポートをすると記録が一致します。 体の記録は消えません）。
  • ページを再読み込みします。
  • ブックマークを削除します。

    • 注意事項

    • 非公式のツールです。このツールについて Daily Akari の作者に問い合わせないでください。
    • Daily Akari の非公開の仕組みを利用しているため、Daily Akari の更新によって動かなくなることがあります。
    • 記録は外部へ送信しません。通信するのは、このツール本体（tracker.js）の読み込みと、Daily Akari のサイトからの問題一覧の取得だけです。
    • Daily Akari 本体の保存データは読み取るだけで、書き換えません。
    • 検証しているのは Android 版 Chrome です。そのほかのブラウザでは動かないことがあります。

    ブックマークレットは、このページで表示されたコードをそのまま使ってください。出どころの分からないコードをブックマークレットとして実行するのは危険です。
